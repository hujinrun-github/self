# 动效与交互优化

沿用作品集现有蓝灰配色、字体和布局，重点是短促的操作反馈。没有新增动画依赖。

## 展示与操作

- 首页文案、展示图与图中节点完成一次入场，最长约 740ms，没有常驻漂浮动画。
- 按钮提供轻按压反馈；指针设备上的链接箭头、项目图标和社交链接有轻微响应。
- 手机导航以 220ms 展开和收起。收起时立即禁止键盘进入，切回桌面恢复正常导航。
- 手机文章目录以浮层展开，保持正文位置；目录箭头有展开反馈。
- 点赞、评论提交和加载更多显示等待状态；服务器确认点赞后才播放心形反馈。
- 后台导航、表单、弹窗和遮罩使用同一套短动效。
- 系统开启“减少动态效果”时，关闭动画、过渡和平滑滚动。

## 查找与阅读

- 写作与项目列表支持本地搜索标题、摘要、标签和技术，可清空搜索并返回输入框焦点。
- 显示匹配数量、无匹配提示、加载状态和失败重试；切换资源或语言时忽略并取消旧请求。
- 真实空列表保留原有展示占位，不把搜索无匹配或加载失败当作空库。
- 普通页面跳转从顶部打开，不沿用上一页的滚动位置；不覆盖浏览器返回或带锚点的跳转。
- 文章导航下方有 2px 阅读进度线，仅计算正文，不包含评论。目录跟随顶部阅读位置，不因进度达到 100% 提前选中末节。
- 滚动测量使用 requestAnimationFrame，处理窗口、图片与正文高度变化，卸载时移除监听；正文不会每次滚动都重新解析。
