# 手帐功能设计方案

日期：2026-10-02  
状态：用户已确认，已完成实现、验收并部署上线（2026-10-03）。实现与验证说明见文末；[部署记录](../../project_info/deployments/20261003-003459/report.md)。

## 1. 定位与访问范围

在现有个人作品集后台增加独立的「手帐」，方便随时记录生活片段、照片、心情与灵感，再按日期回看。根据本轮反馈，**画布是首版主要的记录与展示形式**：打开一页纸，自由摆放文字、照片、便签与基础贴纸，保存后仍按原样回看。

建议结构为 **手帐本 → 一篇记录／一页有边界的纸张画布 → 多个可编辑元素**。固定页面边界便于构图、手机回看和导出，纸张可选纵向或横向；无限画布留作后续探索，当前反馈不视为已确认无限白板需求。时间流和月历负责找到记录，进入记录后以画布为主。

已确认的访问方式为：**管理页面正常登录后直接查看和编辑；首页展示无需用户登录，查看具体手帐内容时输入密码。** 每本手帐设置独立的前台查看密码，管理员在后台设置或更换，并自行交给希望查看的对象。

网站首页可以有「手帐」栏目。只有已设置查看密码且开启前台展示的手帐本才进入公开目录；未解锁时仅展示管理员明确确认可公开的非敏感本名、装饰封面或默认锁封面，不加载记录正文、摘要、画布预览和附件。访客输入该本密码后只读浏览，不需要注册或登录。

本方案通过密码分发控制查看范围，不建立访客账号或账号白名单。知道密码的人都能查看已开放的对应手帐本，系统无法识别密码转发后的实际查看者；停止使用旧密码需要管理员更换密码，并将新密码自行交给仍希望授权的对象。后台管理权限独立于前台密码，管理员无需再次解锁。

现有「写作」继续承载需要标题、摘要、发布与多语言管理的正式文章。手帐使用独立数据与简化流程：打开即可写，标题、心情、天气和标签均不必填。

## 3. 信息架构

后台侧栏在「写作」附近增加「手帐」，进入 `/admin/journal`，沿用现有管理员登录。首页增加「手帐」栏目并可进入 `/journal` 目录；访客无需登录即可浏览已开放手帐本的公开展示卡片，点击后输入对应密码进入只读阅读页。

```text
手帐
├── 所有记录：默认时间流，可切换月历
├── 手帐本：日常、旅行、灵感；可新建、改名、归档
│   └── 前台展示设置：查看密码、展示开关、公开本名与封面、预览
├── 收藏
├── 搜索与筛选：关键词、日期、手帐本、标签、心情
├── 回收站
└── 导出：所选记录、某本手帐或全部记录
```

首次进入时引导创建一本「日常」，可立即在后台记录；「旅行」「灵感」作为可选分类建议，不要求先整理分类。前台展示默认关闭，管理员希望展示时再设置查看密码、确认公开卡片字段并开启。未配置密码时不能开启前台展示，清除密码时同时关闭展示并使旧访客凭证失效。

每条记录归属一本手帐，继承该本的前台展示状态与查看密码，首版不叠加单篇例外权限。记录可有多个标签，也可收藏。前台解锁后仅能读取该本已保存且未删除的记录，不包含编辑页中尚未保存的内容、回收站或临时上传附件。归档手帐本后保留后台记录与检索能力，并关闭前台展示；删除手帐本前必须先迁移或处理其中记录。移动记录到另一本时提示目标本的前台展示状态并确认，避免记录意外进入已开放的手帐本。

公开目录使用独立的展示字段：管理员可确认公开本名，封面默认为通用锁封面，也可选择不含手帐正文照片的非敏感装饰封面。目录不从画布自动截取封面，不展示记录数量、日期标记、摘要或标签。关闭展示的本不出现在目录，访客直接访问其链接或 API 也无法读取。

### 后台桌面端

- 保留现有后台导航和蓝灰色系；手帐内容区域使用更柔和的纸张底色。
- 顶部提供时间流／月历切换、搜索与「记一页」。
- 时间流按发生日期倒序分组，卡片以整页画布缩略图为主，附日期、可选标题、心情与标签；纯文字页可附文字摘要。
- 辅助栏放「记录今天」和手帐本快捷入口，收藏和标签纳入筛选。月历视图点击日期定位当天，点击记录打开编辑详情。
- 编辑器中心是纸张画布，工具栏提供文字、照片、便签、基础贴纸和模板，左侧为页面预览；选中元素后在右侧展示相关属性与图层。顶栏放撤销／重做，画布下方放缩放与适合页面，保存状态始终可见，手帐本、日期等放在页面设置中。

### 后台手机端

- 顶部保留标题、搜索和视图切换，分类筛选收进抽屉。
- 时间流使用单列画布预览卡片，提供容易触达的「记录」入口。
- 编辑器默认展示整页概览，保持桌面上的元素位置与比例，不自动重排。轻点元素后在底部面板编辑文字或属性；键盘打开时确保输入区域可见，支持回到整页查看。
- 明确区分「移动页面」和「选择元素」模式；双指平移／缩放视口，选择模式下单指拖动已选元素，减少误移动。细小元素可先放大再选择，也可从图层列表选中。
- 图片入口支持拍照或从相册选择，实际拍照能力遵循设备浏览器支持情况。
- 月历日期展示记录标记；选择一天后列出当天全部记录，并提供补记入口。
- 延续项目现有规范：主要操作区域至少 44px，输入字号至少 16px，支持减少动态效果。

### 前台阅读端

- 首页和手帐目录直接显示可公开的本名及锁封面；点击卡片展示密码输入框，不出现注册、登录或邀请激活流程。
- 解锁成功后显示该本的时间流、月历与只读画布；桌面和手机均保持原有排版，支持缩放与翻页，不显示编辑、管理和导出操作。
- 未解锁时不请求正文、摘要、场景或私有图片；不能通过先加载内容再模糊或遮挡的方式保护手帐。
- 阅读页显示「已解锁」和「锁定」操作，凭证到期后回到密码输入状态；后台管理员阅读和编辑不受该访客锁定状态影响。

## 4. 记录体验

后台推荐主流程：**管理员登录 → 点「记一页」→ 空白页或模板 → 添加并摆放元素 → 自动保存 → 按日期回看。** 整个管理流程不要求输入手帐查看密码。

1. 新记录默认当前发生日期、最近使用的手帐本和纸张样式；空白页可直接点「文字」开始输入，未添加内容的页面不占据时间流。
2. 标题可省略。首版元素包含文字、照片、便签和少量内置贴纸；文字支持基础格式、列表和待办，照片可更换、调整显示尺寸并补充说明。纯文字、纯照片记录都成立。
3. 元素可拖动、缩放、旋转、复制、删除、锁定，并调整前后层级。提供对齐参考线与吸附开关；照片默认等比缩放，文字框调整宽度时重排框内文字。模板只是预先摆好的元素，每个元素仍可独立编辑。
4. 心情提供少量直观选项，可跳过；天气为可选手填，不请求定位、不自动读取天气。
5. 同一天可以创建多条记录，也可补记历史日期。发生日期与系统创建时间分开保存，修改补记日期不影响真实创建时间。
6. 编辑页显示「前台未展示」或「前台展示 · 密码查看」，管理员可打开前台展示设置和预览公开卡片。已开启展示的本，其已保存记录会向持有有效密码的访客提供只读访问，编辑保存状态旁明确提示这一范围。前台不显示编辑工具，所有写操作仍由服务端检查管理员会话。

### 画布操作规则

- **视口与内容分开**：放大、缩小、适合页面、平移只改变看画布的方式，不改变元素坐标；选中元素后出现边框和变换手柄，才会改变元素本身。
- **图层与锁定**：图层列表展示元素类型与可读名称，支持选中、前移／后移、置顶／置底和锁定；锁定元素可从列表解锁，避免遮挡后无法找回。
- **撤销／重做**：覆盖添加、编辑、移动、变换、删除及层级操作；一次连续拖动记为一步，自动保存不清空当前编辑会话的撤销历史。
- **操作替代入口**：触摸端使用足够大的手柄和明确模式；键盘支持切换选择、方向键微调、删除、撤销／重做。属性面板提供位置、尺寸与角度输入，让精确排版不依赖拖动；文字输入时不触发画布快捷键。
- **页面边界**：首次选定纸张后以固定坐标保存；变更方向或尺寸需预览布局影响，不能静默裁掉元素。首版一篇记录一页，多页记录后续再扩展。

### 模板与纸张

| 模板 | 初始内容 | 适用场景 |
| --- | --- | --- |
| 随手记 | 空白画布，可立即添加文字或照片 | 一句话、一张照片、临时灵感 |
| 今日小结 | 日期文字、照片位与三张提示便签 | 晚间回顾 |
| 旅行记录 | 标题、两张照片位、路线与见闻文字框 | 出游补记 |

模板插入可自由修改的元素。已有内容应用模板应先预览并选择另建一页或合并，不能直接覆盖。

纸张提供白纸、横线和点阵；样式只影响背景，不改变元素位置和文字。横线和点阵保持低对比度，避免干扰阅读。

## 5. 前台密码查看与后台管理

### 权限与设置

| 身份／状态 | 可执行的操作 |
| --- | --- |
| 已登录的后台管理员 | 直接查看、编辑、管理手帐、设置前台密码与展示范围、导出；无需手帐二次解锁 |
| 前台访客，尚未解锁 | 无需登录；仅浏览已开放手帐本的公开展示卡片和密码输入页 |
| 前台访客，持有该本有效解锁凭证 | 只读浏览该本已保存且未删除的记录、画布和图片；默认无导出权限 |
| 前台访客，凭证过期或密码版本已失效 | 只能读取仍允许公开的卡片字段，重新输入密码后才能继续阅读内容 |
| 手帐未设置密码或未开启前台展示 | 不进入公开目录，前台内容与解锁 API 拒绝访客访问；管理员仍可在后台直接操作 |

管理员在「前台展示设置」中管理三个区域：**查看密码**（设置／更换，不展示已保存密码）、**展示开关**（默认关闭，配置密码后才可开启）、**公开卡片**（明确确认本名及非敏感装饰封面，默认锁封面）。密码遗忘时直接在已登录后台设置新密码，无需输入旧的手帐密码；后台管理操作始终遵守现有管理员会话校验。

管理员自行把查看密码交给指定对象。系统不新增访客账户、邮箱验证、邀请激活或指定账号名单，也不能按实际个人撤销同一个共享密码；需要收回旧密码的访问能力时，更换该本密码即可。本轮只做设计，不采集实际密码，也不向任何人发送密码。

### 查看与解锁流程

前台流程：**打开首页手帐栏目 → 选择已展示的本 → 输入查看密码 → 进入只读画布。** 全程不要求用户登录。后台流程：**管理员正常登录 → 直接查看、编辑或导出。**

- 每本手帐独立解锁，访客无需每打开一页都重新输入密码。建议默认 15 分钟无操作后锁定，并设置最长一小时的凭证有效期；访客也可主动锁定当前本。解锁不同本互不代替。
- 服务端先检查该本已开启前台展示且已配置密码，再验证输入。成功后颁发短期、不透明的访客解锁凭证，通过 `HttpOnly`、`Secure`、`SameSite=Lax` Cookie 保存；服务器按本维护解锁会话，绑定手帐本、密码版本与到期时间。它是匿名浏览器会话，不代表实名用户或账号授权，不靠浏览器里的 `unlocked=true` 放行。
- 每次读取记录、摘要、场景、原图或预览均检查该本展示开关、密码版本和有效解锁会话。解锁 A 本不能读取 B 本，接口中的记录或附件 ID 必须核对实际所属本。
- 更改密码、清除密码或关闭前台展示时，使旧访客解锁会话失效；即使之后重新开启展示，旧会话也不能恢复。服务端立即拒绝旧凭证的后续请求，已打开页面在下一次权限校验或恢复前台时收起内容，不能继续取图或翻页。已看到或另行保存的内容无法追回。
- 锁定后清除前台界面中的场景、图片对象 URL 和受保护预览。服务端时间决定解锁期限，图片加载或后台轮询不能无限延长有效期。仅允许明确的前台交互刷新空闲时间，不能延长最长有效期。
- 管理员会话与访客解锁会话分开处理：访客凭证不能调用任何后台接口；后台通过正常管理员权限直接读取，设置或更换前台密码不影响管理员编辑与保存。

密码仅保存经过加盐的慢哈希，使用成熟密码库；不保存明文或可逆密文，不写入日志、链接或前端持久状态。前台解锁按手帐本、请求来源及匿名会话组合限流和退避，错误反馈不暴露受保护的记录信息。后台登录继续使用现有登录限流。密码保护表示访问控制，不能据此宣称端到端加密或账号白名单。

## 6. 保存、回顾与数据安全

### 保存反馈

- 文字输入停顿或完成元素操作后自动保存页面场景，并提供手动重试；拖动过程不逐帧请求服务器。
- 状态区区分「正在保存」「已保存于 14:32」「离线，修改暂未同步」「保存失败，点击重试」，只有服务器确认成功才显示已保存。
- 首版未同步场景仅保留在当前编辑页内存，不将私密正文、布局和附件写入 LocalStorage／IndexedDB。离线时提示尚未同步且刷新或关闭可能丢失，恢复连接并通过鉴权后重试；已保存版本可重新加载。需要刷新恢复的持久草稿列入后续加密存储方案，不与密码锁功能一起承诺明文离线恢复。
- 附件分别展示上传中、成功或失败；上传未完成时不能把整篇记录显示为全部已保存。离线选中的附件提示恢复网络后重新上传。
- 使用版本号或 ETag 检测多端冲突。发现其他设备更新时保留本地整页场景，提供另存副本与载入最新版本；首版不自动合并元素位置，也不承诺画布差异比较，不能静默覆盖。
- 有未同步内容时离开页面或退出后台给出保存／放弃提醒，再清理页面；管理员会话到期时隐藏内容并停止写请求，未同步修改仅暂留当前页内存，重新登录后台后可恢复，页面关闭仍可能丢失。管理端草稿与前台访客解锁状态无关，不要求输入手帐查看密码。

### 回顾与导出

- 后台时间流、月历和搜索按管理员权限直接查询，无需解锁手帐；前台只查询当前访客已解锁且仍开启展示的本。筛选条件保持一致，月历一天有多条时显示数量或标记；前台未解锁内容不计入日期标记、记录数量或搜索摘要。
- 支持按日期范围、手帐本、标签、心情与收藏筛选；关键词检索标题、文字／便签内容及照片说明，搜索命中后打开对应画布。
- 删除记录进入回收站，保留 30 天，可恢复；彻底删除需明确确认，并按附件引用关系处理清理。
- 仅后台管理员可导出 PNG 或 PDF，保留纸张、元素位置、旋转与层级，适合打印和长期阅读；导出前确认管理员会话有效且字体及附件加载完成，无需输入手帐密码。所选记录、一本或全部记录均可批量导出，PDF 每篇一页。首版前台不提供导出入口或访客导出接口，后台导出 API 拒绝仅持有访客解锁凭证的请求。
- 后台提供可恢复的场景 JSON + 原始附件 ZIP，保存页面尺寸、元素、版本格式及发生日期、标签等元数据，并支持在本系统恢复。Markdown 仅作为文字内容与照片引用的补充提取，会丢失自由布局、旋转和装饰，不作为完整备份。缺失附件必须提示，不能默默输出不完整文件。

### 私密内容的交付前提

当前项目媒体通过 `/uploads/*` 和 `/media/{id}/{variant}` 公开访问，后者还使用长期公开缓存。手帐正文附件需要独立的私有存储边界；后台请求验证管理员会话，前台请求验证所属本的展示开关、密码版本与有效访客解锁凭证。缩略图、预览、搜索结果和原图均遵守对应访问规则，导出文件仅允许管理员读取。通过受保护接口读取这些素材，使用 `Cache-Control: private, no-store`，不生成永久公开 URL 或可绕过改密检查的长期下载链接。请求中的记录或附件 ID 必须校验实际所属手帐本，防止跨本访问。

首页目录、分享元数据等公共展示只能使用管理员明确确认的公开本名和非敏感装饰封面，或默认锁封面；不把正文图片作为公开封面。未解锁时不返回记录标题、摘要、日期标记、标签、画布或正文附件，也不把这些内容写入公开 HTML、页面源码或网站地图。公开展示字段与受保护内容分别查询和返回，不能先下发正文再用遮罩隐藏。

`PRIVATE_UPLOADS_DIR` 当前仅存放处理中的临时原图，会被清理且不参与备份，不能直接作为手帐永久附件目录。首版必须建立持久私有附件存储及对应备份／恢复流程，验证数据库与附件能够一起恢复。

本方案提供后台管理员鉴权与前台密码查看，**不提供端到端加密**；拥有服务器或数据库管理权限的人仍可能访问内容。界面不能宣称「只有指定账号能看」或「只有你能解密」。前台展示和密码变更留审计记录，但不记录密码或手帐正文。

## 8. 与现有项目的结合

项目当前为 React + TypeScript + Vite 前端、Go + chi 后端和 PostgreSQL 数据库，以单个服务部署。现有登录与会话绑定 `admins`，管理端继续沿用这一机制；前台无需新增用户体系，仅增加匿名访客的按本解锁会话。

管理员通过 `/api/admin/journal/*` 直接管理、查看和导出，接口只检查正常管理员权限，不要求前台解锁凭证。前台提供独立的公开目录、按本密码验证和只读内容接口；公开目录只返回允许的展示字段，受保护内容接口检查该本已开放及有效访客凭证。可以复用现有会话、CSRF、密码哈希和限流的实现模式，但不能让访客凭证获得后台管理权限。

首版建议采用 React 管理编辑界面和页面场景，通过场景图层渲染元素及变换控制；文字进入编辑时用 DOM 输入／富文本覆盖层，避免直接在绘图表面处理输入法。候选绘图库在实施时验证中文输入、触摸变换、字体与 PNG／PDF 输出一致性后再确定。场景坐标独立于屏幕像素，手机与桌面使用相同数据与渲染规则。

可复用基础图片处理、媒体引用追踪和交互组件，现有文字编辑能力需适配到独立文字元素；画布编辑、私有媒体读取、手帐数据、自动保存和恢复逻辑需要新建。现有 ETag 冲突保护可借鉴其模式，仍需为整页场景单独实现。

建议的核心数据实体：

- `journal_notebooks`：管理员归属、名称、封面／颜色、默认纸张、排序、归档时间、查看密码哈希、`password_version`、前台展示开关及独立的公开展示本名／封面字段。
- 访客解锁会话：随机凭证的安全摘要、手帐本 ID、密码版本、解锁时间、最后有效交互时间、到期时间和撤销状态。仅代表匿名浏览器对某本的临时访问能力，不关联新增访客账号；每次受保护请求检查实时展示状态和密码版本。关闭展示或清除密码时撤销既有会话，重新开启不能恢复旧凭证。
- `journal_entries`：所属手帐本、可空标题、发生日期／可选时间、时区、心情、手填天气、收藏状态、记录版本号、创建／更新时间、删除时间；场景可用 JSONB 保存，并维护可检索文字与私有预览图。
- 页面场景：格式版本 `schemaVersion`、纸张宽高／方向／背景、元素数组；元素有稳定 ID、类型、位置、尺寸、旋转、层级、锁定状态及文字／样式／私有附件 ID。视口状态与页面内容分开，文件不内嵌在场景 JSON 中；格式升级保留迁移能力。
- `journal_tags` 与记录标签关联：首版与公开文章标签隔离，避免私密标签被公开枚举。
- 私有媒体及引用：文件、缩略图、存储位置、所属记录、上传状态；建立明确访问策略，确保原图与派生图一致。

发生日期使用明确的日历日期表达，时间与时区单独保存，避免补记或跨时区后日期漂移。首版按本提供前台展示开关与明确的公开字段，不给正文生成公开 SEO 内容或文章式发布状态；不新增访客 users、members 或 invites 数据模型。

## 9. 评审与验收重点

本轮已纳入画布、后台直接管理及前台密码查看。管理员正常登录后直接查看、编辑和导出；首页与手帐目录无需用户登录，访客输入对应手帐本密码后只读查看。管理员自行向指定对象分发密码，系统不识别实际个人或阻止密码转发。

实施后至少验收以下场景：

1. 新建空白页后可立即添加文字或照片；不填标题、心情和标签也能保存，纯照片记录可以成立。
2. 同一天多条记录、补记历史日期、跨月月历与关键词筛选结果一致。
3. 元素移动、缩放、旋转、层级与锁定可用，撤销／重做恢复正确；视口缩放不改变内容坐标，重新打开后的画布与保存前一致。
4. 上传中、保存中、断网、请求失败、会话失效状态真实可见；当前页保留未同步修改并提示关闭可能丢失，不出现虚假的「已保存」；两台设备冲突可保留整页副本。
5. 前台不登录也能查看已开放手帐本的公开本名和锁封面；未解锁、密码错误或凭证过期时，直接访问记录、摘要、原图、缩略图或画布预览均无法获取内容。输入正确密码后可阅读对应本，无须账号；替换 URL 中的记录／本／附件 ID 不能跨本越权。未配置密码或未开启展示的本不进入公开目录，访客解锁和内容 API 均拒绝访问。
6. 回收站可恢复记录；PNG／PDF 外观与画布一致，场景包可恢复元素、元数据与图片；备份可恢复数据库及全部私有附件。
7. 320px、390px 手机和桌面可完成新建、拍照／选图、元素编辑、保存、搜索与回看；触摸移动页面与拖动元素不混淆，键盘操作和输入法正常；键盘弹出、长文字框、横屏和减少动态效果均可正常使用。
8. 管理员正常登录后，在手帐未设置密码、前台未展示或访客凭证过期的情况下，仍可直接查看、编辑和导出，不出现手帐二次密码框。访客即使已解锁也不能调用编辑、密码设置、导出或其他后台接口；搜索、月历、数量和标签只读取已解锁且开放的本，不泄露其他内容。
9. 更改或清除密码、关闭前台展示后，旧访客凭证和素材访问立即在后续请求中失效，重新开启不能恢复旧凭证；前台锁定和过期后清理界面内容。密码重试受到限流，密码不出现在响应、日志、链接或持久前端状态中。公开页面源码不预载正文或私密图片再用模糊遮罩隐藏。

可交互草图使用示例内容，未连接实际后台权限或密码服务；前台目录、密码阅读与后台直接管理的行为以本文为准。实际管理员鉴权、访客密码验证和私有素材保护均需由服务器实现，草图中的解锁交互不代表已完成安全功能。
