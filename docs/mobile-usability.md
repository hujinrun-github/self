# 手机操作适配

沿用现有蓝灰视觉样式，覆盖前台、后台内容表单、媒体管理、文章互动和 Markdown 工作台。

- 手机主要操作区域至少 44px，表单输入使用 16px 字号，保留页面缩放。
- 后台内容和资料表单底部提供保存入口；译文仍独立保存，不使用会遮挡键盘的固定保存条。
- 手机编辑器使用源码、所见即所得、预览三个模式，常用格式常驻，其他功能在“更多工具”中。低高度触屏横屏沿用手机工具；鼠标桌面保留分屏。
- 编辑器全屏及弹窗响应可见视口变化，支持短屏滚动、嵌套插入窗口和关闭返回。页面为安全区域及支持的软键盘视口调整预留空间。
- 前台文章提供顶部折叠目录和返回列表；选择目录项后收起，标题为吸顶导航预留滚动空间。标题锚点在重复渲染时保持稳定。
- 手机文章互动统计按文章展示卡片；宽屏保留表格。代码和 Markdown 表格可在自身区域横向滚动。

## 本地验证

2026-10-02 使用 Chrome 触屏模拟检查 320、390、430px 手机宽度、768px 平板及 844×390 横屏，另以 1440px 鼠标桌面回归。73 个页面与尺寸组合无整页横向溢出。

实际操作覆盖菜单打开与外点关闭、三语言导航、目录跳转、后台抽屉、底部保存入口、统计卡片筛选、源码格式和撤销、所见即所得与源码同步、表格／图片／代码弹窗，以及 390×480 短视口全屏。检查过程中未保存或替换原有文章正文。

前端 208 项测试、构建与修改范围 ESLint 通过；后端构建和真实 PostgreSQL 竞态测试通过。截图及检查数据保存在忽略目录 `data/style-preview/mobile/`。原生 iOS Safari 和真实手机软键盘未单独验收，短视口模拟不等同于原生系统键盘测试。
